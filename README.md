# Kinetix Lab 🤖🚁

A workbench for tracking personal robotics and drone projects, managing hardware components, and resolving technical issues with AI support. Built using Google AI Studio.

---

## 📌 Features

- **Project Tracking:** Keep tabs on various robotics and drone builds, milestones, and firmware updates.
- **Issue Helper:** AI-assisted troubleshooting and problem-solving for robotics, hardware, and control systems.
- **Interactive Workbench:** A clean, responsive dashboard to manage specs, components, and project logs.

---

## 🛠 Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS (or standard CSS)
- **AI Integration:** Google AI Studio (Gemini API)
- **Runtime / Server:** Node.js / Express (or Deno)
